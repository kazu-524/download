# 添付ファイル一括ダウンローダー（Edge 拡張機能）

JavaScript で作られたページ（画面がその場で組み立てられるタイプ）から添付ファイルを見つけて、選んだものをまとめてダウンロードします。Edge と Chrome の両方で動きます。

## Edge への入れ方

1. GitHub のリポジトリページで「Code」→「Download ZIP」を押してダウンロードし、展開します。
   展開したものの中にある `edge-attachment-downloader` フォルダを、Windows 側の分かりやすい場所にコピーします。
   - 例：`C:\Tools\edge-attachment-downloader`
2. Edge のアドレス欄に `edge://extensions` と入力して開きます。
3. 左側の「開発者モード」をオンにします。
4. 「展開して読み込み」を押し、手順 1 のフォルダを選びます。
5. ツールバーのパズルのアイコン →「添付ファイル一括ダウンローダー」の目のアイコンを押すと、ツールバーに常に表示されます。

> 入れる前から開いていたタブは、一度再読み込みしてから使ってください（リンク以外のファイルも拾えるようになります）。

## 使い方

1. 添付ファイルがあるページを開き、添付の一覧を画面に表示させます。
2. ツールバーの青い矢印アイコンを押します。
3. 見つかったファイルが一覧になります。種類（PDF・Office・圧縮など）や名前で絞り込めます。
4. 欲しいものにチェックを入れて「○件をダウンロード」を押します。

- 「フォルダに分けて保存」をオンにすると、ダウンロードフォルダの中にサブフォルダを作って保存します。
  `{host}`＝サイト名、`{date}`＝日付、`{time}`＝時刻、`{title}`＝ページ名 に置き換わります。
- 一覧の「推定」は、URL の形からファイルらしいと判断したものです。最初はチェックが外れています。
- ログインが必要なサイトでも、ブラウザのログイン状態のままダウンロードします。

## ファイルの見つけ方（3 通り）

| 表示 | 中身 |
|---|---|
| ページ内 | 今の画面にあるリンク・ボタン・埋め込み（後から表示された部分、iframe の中、Shadow DOM の中も含む） |
| 通信 | ページが裏で受け取ったファイル（添付指定・PDF・Office・ZIP など）の記録 |
| ページで生成 | JavaScript がその場で作ったファイル（Blob）。fetch で受け取ったものはサーバーが付けた名前を使います |

## できないこと・注意

- ボタンを押したときに初めてファイルを取りに行くタイプは、押すまで一覧に出ません。一度開くと「通信」に記録されるので、まとめて取り直すときに使えます。
- POST 送信で返されたファイルは取り直せません（一覧では選べない状態で表示）。ページがその中身を Blob として持っている場合は「ページで生成」から保存できます。
- Edge の設定「ダウンロード時の動作を毎回確認する」がオンだと、1 件ごとに保存ダイアログが出ます。
- 開発者モードの拡張機能は、Edge の起動時に警告が出ることがあります。会社の PC では、管理者の設定で入れられない場合があります。
- ファイルを書き換えたときは、`edge://extensions` でこの拡張機能の「再読み込み」を押してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の設定 |
| `background.js` | 通信の記録、ダウンロードと保存名・フォルダの決定 |
| `hook.js` | ページ側で Blob（その場で作られたファイル）を見張る |
| `content.js` | 画面を調べてファイルを集める |
| `common.js` | 拡張子の分類、ファイル名の整形 |
| `popup.html` / `popup.css` / `popup.js` | 一覧画面 |
| `icons/` | ツールバーなどに出るアイコン |
